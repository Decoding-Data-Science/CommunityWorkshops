02 | Simulations

Labs

Change a setting and watch what happens. Labs marked "toy" use a simplified model so the idea is visible. They never pretend to be Gemini.

Chunking lab

The real DDS Leave Policy v2 text (about 11,000 characters). The amber band is the notice table in section 3.4 (7, 14 and 30 days). If a chunk boundary cuts through it, the bot may read only part of the table.

Sizes here are in characters. LlamaIndex counts tokens (about 4 characters each) and cuts at sentence ends. This lab cuts at exact characters, so counts differ a little from the notebook.

Retrieval and top_k lab (toy)

A question is compared with every chunk. The best top_k chunks go to Gemini. This toy retriever uses keywords plus a few synonyms so you can see the ranking. Real Gemini embeddings understand meaning far better.

Embeddings and dimensions lab

An embedding is a list of numbers. The number of numbers is the dimension. The vector database index must use the same dimension as the embedding model.

Phrases with similar meaning sit close together, even without shared words. The bot finds "annual leave" for a "vacation days" question because they are neighbours.

Agent router lab

An agent reads the question, picks the tool, reads the result and writes the answer. Employee data below is real, from dds_leave.db. The reply text is a simulation of what DecoBot is told to say, not a live Gemini call.

Today in the simulation is 2026-10-28. Notice rule: 1-2 working days need 7 calendar days, 3-9 need 14, 10 or more need 30.

Cost calculator

Gemini API prices in US dollars per 1 million tokens, from Google's pricing page checked on 30 Oct 2026. Prices are editable. Always confirm on ai.google.dev/gemini-api/docs/pricing before you budget.

input tokens  = calls x (system 330 + tools 400 + question 30)
              + top_k x chunk tokens + tool output 150 x (calls - 1)
output tokens = answer 120 + 40 x (calls - 1)
cost / question = input x in-price + output x out-price
embedding (one time) = chunks x chunk tokens x $0.15 / 1M
vector storage = vectors x dimensions x 4 bytes
Assumptions are rounded teaching values. Real usage depends on your prompt length and how often the agent loops.

Worth a look

14 requests are dated after the simulated today (2026-10-28). 9 approved requests overlap an earlier one for the same person. Synthetic data, so we note it.

Rule of the data

Working days are Monday to Friday, no public holidays removed. Approved and started by 28 Oct 2026 means used. Approved and later means booked. Pending, Rejected and Cancelled do not count.

07 | Putting it online

Colab to a live website

Teach in Colab. Publish on Hugging Face Spaces. Render is the optional second home.

Hugging Face Spaces
  1. Create a new Space. Choose the Gradio SDK.
  2. Upload app.py, requirements.txt, and the data folder (PDF and database).
  3. In Settings, add secrets GOOGLE_API_KEY and PINECONE_API_KEY.
  4. The Space builds on its own. Open the link and test with the demo employees.
Render (optional)
  1. Push the project to GitHub. The real keys must never be in the repository.
  2. In Render choose New, then Web Service (or Blueprint with render.yaml).
  3. Build: pip install -r requirements.txt. Start: python app.py.
  4. Add the two keys under Environment. Free plans sleep when idle, so the first load can be slow.

09 | Honest limits

What to know before class

Untested live

The Gemini and Pinecone calls were not run end to end by the builder. Run each notebook once with your own keys.

Policy quirks

The policy does not define the probation period (the handbook only says "as stated in the employment contract"). Section 1 points to 4.4 for extended illness, but the content is in 5.4.

Not security

A prompt that says "refuse other people's data" is not security. A real site needs company login and tools locked to the signed-in employee.

Prices move

Gemini prices change, some on fixed dates. The calculator is a planning tool, not an invoice.
